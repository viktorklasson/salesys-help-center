# Kom igång med SaleSys

## Kort version

SaleSys är en komplett plattform för försäljning och kundhantering. Systemet hjälper dig att hantera ordrar, skicka avtal, ringa samtal, hantera kontakter och följa upp statistik -- allt samlat på ett ställe.

Som ny användare loggar du in med de uppgifter du fått från din administratör. Navigeringen i toppen av sidan ger dig snabb tillgång till alla huvudfunktioner. Vilka funktioner som syns beror på vilka rättigheter du har och vilka funktioner din organisation har aktiverat.

De vanligaste uppgifterna är att skapa ordrar, skicka avtal till kunder, ringa kontakter via ringlistor och följa upp resultat i statistikvyer. Alla inställningar hanteras under kugghjulsikonen i navigeringen.

## Fullständig guide

### Översikt över systemet

SaleSys är uppdelat i följande huvudområden:

| Område | Beskrivning |
|--------|-------------|
| **Ordrar** | Skapa och hantera försäljningsordrar med anpassade fält, taggar och produkter |
| **Avtal** | Skicka digitala avtal till kunder för signering via e-post eller SMS |
| **Samtal** | Ring kontakter automatiskt via ringlistor med stöd för prediktiv uppringning |
| **Kontakter** | Hantera kund- och prospektregister med anpassade fält och taggar |
| **Kalender** | Schemalägg händelser och synkronisera med externa kalendrar |
| **Statistik** | Skapa dashboards och följ upp försäljningsresultat i realtid |
| **Produkter** | Konfigurera produktkategorier, prissättning och produktfält |
| **Inställningar** | Administrera användare, team, roller, funktioner och systemkonfiguration |

### Navigering

Huvudnavigeringen finns i toppen av sidan och innehåller:

- **Samtal** -- Ringlistor, samtalsvy och kontakter (kräver att samtalsfunktionen är aktiverad)
- **Ordrar** -- Orderlista och avtalslista
- **Statistik** -- Dashboards och aktivitetslogg (för administratörer), eller enbart dashboards (för vanliga användare)
- **Kalender** -- Veckokalender med händelser
- **Inställningar** -- Kugghjulsikon som öppnar alla inställningssidor

### Roller och rättigheter

Systemet har tre typer av användare:

1. **Administratör** -- Fullständig tillgång till alla funktioner och inställningar
2. **Vanlig användare** -- Åtkomst baserad på tilldelade roller och rättigheter
3. **Systemanvändare** -- Automatiserade konton som normalt är dolda

Rättigheter tilldelas via roller (Settings > Användare > Roller) och kan sättas på team- eller individnivå.

### Funktioner som kan aktiveras

Din administratör kan aktivera och inaktivera funktioner under Inställningar > Funktioner:

- **Kontakter** -- Samla och hantera kontaktuppgifter
- **Samtal** -- Automatisk uppringning och ringlistor
- **Avtal** -- Digitala avtal via e-post och SMS
- **Aktivitet** -- Se företagets aktivitetslogg
- **Kalender** -- Användarkalendrar med synkronisering
- **Projekt** -- Gruppera inställningar och dokument
- **Registreringslänkar** -- Användare kan registrera sig själva
- **Statistik/Dashboards** -- Anpassade statistikvyer
- **Avtalsformulär** -- Skapa avtal från webbformulär

### Vanliga arbetsflöden

#### Skapa en order
1. Gå till **Ordrar** i navigeringen
2. Klicka **Lägg till**
3. Fyll i orderfält, välj produkter och taggar
4. Spara ordern

#### Skicka ett avtal
1. Gå till **Avtal** i navigeringen
2. Välj en avtalsmall
3. Fyll i mottagaruppgifter och produkter
4. Skicka via e-post eller SMS
5. Följ avtalets status (Skickat → Läst → Signerat)

#### Ringa kontakter
1. Gå till **Ringlistor**
2. Välj en ringlista och telefonnummer
3. Systemet kopplar upp samtal automatiskt
4. Utvärdera samtalet med taggar efter avslut
5. Fortsätt till nästa kontakt

#### Följa upp statistik
1. Gå till **Statistik**
2. Välj eller skapa en dashboard
3. Lägg till block med relevanta mätvärden
4. Filtrera på datum, användare, team eller taggar

### Språk

SaleSys finns på svenska, norska, danska och engelska. Byt språk under Inställningar > Mitt konto > Språk. Sidan behöver laddas om efter byte.

### Säkerhet

- Alla kontaktuppgifter och orderfält lagras krypterade
- Tvåstegsverifiering (MFA) kan aktiveras under Mitt konto
- MFA skickar verifieringskoder via e-post eller SMS vid inloggning

### Hjälp och support

Om du behöver hjälp, kontakta din administratör eller besök supportavsnittet under Inställningar > Kundservice.
