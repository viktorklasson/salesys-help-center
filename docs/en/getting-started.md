# Getting Started with SaleSys

## Short version

SaleSys is a complete platform for sales and customer management. The system helps you manage orders, send agreements, make calls, handle contacts, and track statistics -- all in one place.

As a new user, log in with the credentials provided by your administrator. The navigation bar at the top gives you quick access to all main features. Which features are visible depends on your permissions and which features your organization has enabled.

The most common tasks are creating orders, sending agreements to customers, calling contacts through lead lists, and tracking results in statistics views. All settings are managed under the gear icon in the navigation.

## Full guide

### System overview

SaleSys is divided into the following main areas:

| Area | Description |
|------|-------------|
| **Orders** | Create and manage sales orders with custom fields, tags, and products |
| **Offers** | Send digital agreements to customers for signing via email or SMS |
| **Calls** | Call contacts automatically through lead lists with predictive dialing support |
| **Contacts** | Manage customer and prospect records with custom fields and tags |
| **Calendar** | Schedule events and synchronize with external calendars |
| **Statistics** | Create dashboards and track sales results in real time |
| **Products** | Configure product categories, pricing, and product fields |
| **Settings** | Manage users, teams, roles, features, and system configuration |

### Navigation

The main navigation is at the top of the page and contains:

- **Calls** -- Lead lists, call view, and contacts (requires the Calls feature to be enabled)
- **Orders** -- Order list and offers list
- **Statistics** -- Dashboards and activity log (for administrators), or dashboards only (for regular users)
- **Calendar** -- Weekly calendar with events
- **Settings** -- Gear icon that opens all settings pages

### Roles and permissions

The system has three types of users:

1. **Administrator** -- Full access to all features and settings
2. **Regular user** -- Access based on assigned roles and permissions
3. **System user** -- Automated accounts that are normally hidden

Permissions are assigned through roles (Settings > Users > Roles) and can be set at team or individual level.

### Features that can be enabled

Your administrator can enable and disable features under Settings > Features:

- **Contacts** -- Collect and manage contact information
- **Calls** -- Automatic dialing and lead lists
- **Offers** -- Digital agreements via email and SMS
- **Activity** -- View company activity log
- **Calendar** -- User calendars with synchronization
- **Projects** -- Group settings and documents
- **Registration Links** -- Users can self-register
- **Statistics/Dashboards** -- Custom statistics views
- **Offer Web Forms** -- Create agreements from web forms

### Common workflows

#### Creating an order
1. Go to **Orders** in the navigation
2. Click **Add**
3. Fill in order fields, select products and tags
4. Save the order

#### Sending an agreement
1. Go to **Offers** in the navigation
2. Select an offer template
3. Fill in recipient details and products
4. Send via email or SMS
5. Track the agreement status (Sent → Read → Signed)

#### Calling contacts
1. Go to **Lead Lists**
2. Select a lead list and phone number
3. The system connects calls automatically
4. Evaluate the call with tags after completion
5. Continue to the next contact

#### Tracking statistics
1. Go to **Statistics**
2. Select or create a dashboard
3. Add blocks with relevant metrics
4. Filter by date, users, teams, or tags

### Language

SaleSys is available in Swedish, Norwegian, Danish, and English. Change language under Settings > My Account > Language. The page needs to be reloaded after switching.

### Security

- All contact details and order fields are stored encrypted
- Two-factor authentication (MFA) can be enabled under My Account
- MFA sends verification codes via email or SMS at login

### Help and support

If you need help, contact your administrator or visit the support section under Settings > Customer Service.
